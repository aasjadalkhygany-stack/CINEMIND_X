
CINEMIND_X - مصادر المشاهدة

ملف المصادر الأساسي:
sources.json

طريقة إضافة مصدر:
1. افتح data/sources.json
2. أضف المصدر داخل items.
3. استخدم معرّف TMDB الصحيح للفيلم.
4. أنواع المصادر المدعومة:
   - mp4
   - hls
   - embed

مثال لمفتاح فيلم:
movie:550

مثال لمفتاح مسلسل:
tv:1396

مثال لحلقة من مسلسل:
tv:1396:1:1

ملاحظة:
روابط الفيديو يجب أن تكون قانونية وصالحة وتسمح بالتشغيل داخل الموقع.
بيانات TMDB لا تعني أن الفيديو متوفر للمشاهدة.
